# 🐄 Livestock Health Assistant — Offline AI for Smallholder Farmers

An offline AI-powered assistant that helps smallholder farmers in Ethiopia identify common livestock symptoms and get structured, practical guidance — no internet connection required.

## Why offline?

Rural connectivity in Ethiopia is inconsistent, but livestock health decisions can't wait. This app runs entirely on-device, so a farmer or extension worker can get guidance anywhere — no data cost, no signal required. **Confirmed working with no internet connection.**

## Features

- **Structured, reliable responses** — every matched condition returns Possible Causes, What You Can Do Now, Warning Signs, and a Recommendation, built from a curated knowledge base (not freely generated by AI, so formatting is always consistent)
- **Confidence rating** — 🟢 High / 🟡 Medium / 🟠 Low, based on how specific the symptom match was
- **Follow-up questions** — relevant clarifying questions shown after each response
- **Animal info collection** — optional age, sex, and weight fields for extra context
- **Photo upload & analysis** — upload a photo (eye problems, skin issues, wounds, swelling); a vision model describes what's visible, and that description runs through the same safety-checked matching pipeline as typed symptoms
- **Voice input** — describe symptoms by speaking instead of typing, transcribed fully offline
- **Full bilingual support (English + Amharic)** — every condition has curated, human-reviewed Amharic text; Amharic symptom input is also supported directly
- **Disease Library** — browsable reference of all known conditions
- **Emergency Guide** — quick-reference of urgent conditions and what to watch for
- **Vaccination Reminders** — local tracker for upcoming/overdue vaccinations
- **Persistent chat history** — conversations save automatically and are browsable from a "Recent" list, like a real chat app
- **Daily prevention tip** — rotates once per day, bilingual
- **Emergency detection is hard-coded**, never left to AI judgment — the model can't accidentally forget to flag something urgent

## How it works

1. Farmer selects the animal type and describes symptoms — by typing, tapping a quick-symptom button, uploading a photo, or speaking
2. The app matches the input against a curated veterinary knowledge base (currently 12 conditions across cattle, goats, and poultry)
3. For matched conditions, a structured response is built from curated data, with a short live-AI-generated opening sentence (English) for a natural feel
4. If a symptom isn't recognized, the app says so honestly rather than guessing

## Tech stack

- **Text model:** Phi-3-mini (via Ollama) — symptom understanding and natural phrasing
- **Vision model:** Moondream (via Ollama) — photo symptom description
- **Speech-to-text:** faster-whisper (tiny model) — offline voice transcription
- **Backend:** Python
- **Interface:** Streamlit — sidebar navigation, chat, disease library, emergency guide, reminders
- **Knowledge base:** Structured JSON — symptoms, causes, actions, warning signs, recommendations, follow-up questions, all bilingual

## Setup

```bash
# 1. Install Ollama, then pull both models
ollama pull phi3:mini
ollama pull moondream

# 2. Clone and install Python dependencies
git clone https://github.com/<your-username>/livestock-health-assistant.git
cd livestock-health-assistant
pip install -r requirements.txt

# 3. Run the app
streamlit run app.py
```

No internet connection is needed after setup — everything runs fully local.

## Known limitations

- Small quantized models occasionally produce imperfect phrasing; response length and format are constrained in code to reduce this
- Currently covers 12 common conditions — not a substitute for comprehensive veterinary knowledge
- Photo analysis describes visible symptoms only; it does not diagnose directly — descriptions are matched against the same knowledge base as typed symptoms
- Voice transcription quality, especially in Amharic, has not yet been extensively validated and should be tested before relying on it in a live demo
- Only English and Amharic are supported; other Ethiopian languages (e.g. Afaan Oromo, Tigrinya) would require native-speaker review before being added responsibly

## Disclaimer

This tool provides preliminary guidance only and does not replace professional veterinary care. In any emergency or when an animal is in visible distress, contact a veterinarian immediately.
